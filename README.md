# Military Duty Roster Scheduler

Αυτόματο σύστημα δημιουργίας μηνιαίου προγράμματος υπηρεσιών για στρατιωτική μονάδα. Φορτώνει δεδομένα προσωπικού και αναγκών από Excel, λύνει το πρόβλημα κατανομής υπηρεσιών με constraint satisfaction, και γράφει το αποτέλεσμα απευθείας πίσω στο ίδιο αρχείο — μαζί με στατιστικά ανά στρατιώτη και αναφορά παραβάσεων.

---

## Stack

- **Python 3** — γλώσσα υλοποίησης
- **openpyxl** — ανάγνωση/εγγραφή `.xlsm` (Excel με macro support, VBA-safe)
- **PyInstaller** — μεταγλώττιση σε standalone `.exe` χωρίς Python εγκατάσταση
- **VBScript** — Windows launchers για εκτέλεση με διπλό κλικ

---

## Πρόβλημα που λύνει

Κάθε μέρα του μήνα πρέπει να καλυφθούν συγκεκριμένες θέσεις υπηρεσίας (slots). Κάθε στρατιώτης έχει διαφορετικούς περιορισμούς: ποιες υπηρεσίες μπορεί να κάνει, πόσες τον μήνα, πόσα Σ/Κ, ελάχιστες μέρες ανάπαυσης μεταξύ τους, και ποιες μέρες της εβδομάδας επιτρέπονται. Το πρόγραμμα βρίσκει βέλτιστη ανάθεση για κάθε μέρα του μήνα αυτόματα.

## Τύποι Υπηρεσίας

| Κωδικός | Slots | Κατηγορία |
|---|---|---|
| ΜΛΣΝ | 4 θέσεις (ΜΛΣΝ1–4) | Κανονική |
| ΕΤΑΦ | 2 θέσεις (ΕΤΑΦ1–2) | Κανονική |
| ΕΣΤ | 2 θέσεις (ΕΣΤ1–2) | Κανονική |
| ΒΑΥΔΜ | 1 θέση | Κανονική |
| ΕΠΙΦ_ΜΛΣΝ | 1 θέση | Εφεδρική |
| ΕΠΙΦ_ΒΑΥΔΜ | 1 θέση | Εφεδρική |

## Δομή Excel (programma_ypiresion_step1.xlsm)

### Sheet: Personnel
Ένας στρατιώτης ανά γραμμή. Στήλες:

| Στήλη | Πεδίο | Περιγραφή |
|---|---|---|
| A | Όνομα | Επώνυμο και όνομα |
| B | Posto | Ειδικός ρόλος (ΚΗΠΟΥΡΟΣ / ΓΔΥ / ΓΕΝΙΚΟ) |
| C | mlsn | 1 = μπορεί ΜΛΣΝ |
| D | etaf | 1 = μπορεί ΕΤΑΦ |
| E | est | 1 = μπορεί ΕΣΤ |
| F | vavdm | 1 = μπορεί ΒΑΥΔΜ |
| G | epif_mlsn | 1 = μπορεί εφεδρική ΜΛΣΝ |
| H | epif_vavdm | 1 = μπορεί εφεδρική ΒΑΥΔΜ |
| I | kanonikos | 1 = μόνιμος (ισχύει 1 υπηρεσία/εβδομάδα) |
| J | mono_1_ton_mina | 1 = το πολύ 1 υπηρεσία τον μήνα |
| K | mono_sk | 1 = μόνο Σαββατοκύριακα |
| L | energos | 1 = ενεργός (0 = παραλείπεται) |
| M | max_mina | Μέγιστος αριθμός υπηρεσιών/μήνα |
| N | max_sk | Μέγιστος αριθμός Σ/Κ υπηρεσιών/μήνα |
| O | min_gap_days | Ελάχιστες ημέρες ανάπαυσης μεταξύ υπηρεσιών |
| P | Σχόλια | Ελεύθερο κείμενο |
| Q | allowed_days | Συγκεκριμένες μέρες εβδομάδας (π.χ. "Δευτέρα,Τρίτη") |
| R–U | max_mlsn/etaf/est/vavdm | Per-service ανώτατα όρια |

### Sheet: Needs
Ανάγκες ανά ημέρα εβδομάδας. Διαφορετικός αριθμός θέσεων για καθημερινές vs Σ/Κ:

| Ημέρα | mlsn | etaf | est | vavdm | epif_mlsn | epif_vavdm |
|---|---|---|---|---|---|---|
| Δευτέρα | 2 | 1 | ... | ... | ... | ... |
| Σάββατο | ... | ... | ... | ... | ... | ... |

### Sheet: Schedule
Το ημερολόγιο του μήνα. Η ημερομηνία έναρξης διαβάζεται από το κελί **B1**.

```
Row 3: headers  → ΗΜΕΡΑ | ΗΜ/ΝΙΑ | ΜΛΣΝ1 | ΜΛΣΝ2 | ... | ΕΠΙΦ_ΒΑΥΔΜ
Row 4: 1η μέρα
Row 5: 2η μέρα
...
```

### Sheet: Stats
Στατιστικά ανά στρατιώτη — παράγεται αυτόματα με τύπους Excel (`COUNTIF`, `COUNTIFS`, `VLOOKUP`). Περιλαμβάνει ΣΥΝΟΛΟ_ΥΠΗΡΕΣΙΩΝ, ΣΥΝΟΛΟ_ΣΚ, ανά τύπο υπηρεσία, και ελέγχους max_mina/max_sk.

### Sheet: Adeies
Άδειες προσωπικού. Στήλες: `ΟΝΟΜΑ | ΑΠΟ | ΕΩΣ` (ημερομηνία επιστροφής, exclusive).

### Κρυφά Sheets (δημιουργούνται αυτόματα)

| Sheet | Σκοπός |
|---|---|
| **Violations** | Αναφορά παραβάσεων μετά από κάθε εκτέλεση |
| **Snapshot** | Αντίγραφο schedule για εντοπισμό χειροκίνητων αλλαγών |
| **CarryOver** | Τελευταίες N ημέρες για συνέχεια μεταξύ μηνών |
| **Exclusions** | Ζεύγη (όνομα, ημερομηνία) που εξαιρέθηκαν χειροκίνητα |

## Περιορισμοί (Constraints)

### Hard Constraints — αποκλεισμός υποψήφιου
| Συνάρτηση | Κανόνας |
|---|---|
| `service_allowed_flag()` | Δεν έχει το flag για αυτή την υπηρεσία |
| `respects_min_gap()` | Υπηρέτησε πιο πρόσφατα από `min_gap_days` |
| `respects_weekly_limit()` | Μόνιμος με υπηρεσία ήδη αυτή την εβδομάδα |
| `respects_max_weekend()` | Έχει φτάσει το `max_sk` |
| `respects_reserve_gap()` | Gap < 3 μέρες μεταξύ κανονικής και εφεδρικής |
| `respects_service_max()` | Έχει φτάσει per-service όριο (π.χ. `max_mlsn`) |
| `posto_allows_service()` | Ρόλος απαγορεύει αυτή την υπηρεσία αυτή τη μέρα |
| `allowed_days` check | Η μέρα δεν είναι στη λίστα επιτρεπτών μερών |
| `mono_sk` check | Είναι μόνο Σ/Κ αλλά η μέρα είναι καθημερινή |
| `mono_1_ton_mina` check | Έχει ήδη 1 υπηρεσία τον μήνα |
| forward gap check | Υπάρχει άλλη ήδη-ανατεθειμένη υπηρεσία πολύ κοντά στο μέλλον |

### Κανόνες Posto
| Posto | Καθημερινές | Σ/Κ |
|---|---|---|
| ΓΕΝΙΚΟ / κενό | Όλες οι υπηρεσίες | Όλες |
| ΚΗΠΟΥΡΟΣ | Όχι ΜΛΣΝ, όχι ΕΣΤ | Όλες |
| ΓΔΥ (ΚΩΣΤΟΥΛΑ) | Όχι ΜΛΣΝ, όχι ΕΣΤ | Όλες |

## Αλγόριθμος Βαθμολόγησης (Soft Constraints)

Αφού αποκλειστούν οι μη-επιλέξιμοι, οι υπόλοιποι ταξινομούνται με `candidate_priority()`:

**Για ΜΛΣΝ / ΕΤΑΦ:**
```
(mono_sk+mono_1_ton_mina_preference, regular_count, weekend_count, name)
```

**Για ΒΑΥΔΜ / ΕΣΤ** (προτιμώνται πιο "περιορισμένοι" στρατιώτες):
```
(mono_sk+mono_1_ton_mina_preference, service_flex, regular_count, weekend_count, name)
```

Όπου `service_flex` = αριθμός τύπων υπηρεσίας που μπορεί να κάνει ο στρατιώτης. Αυτός με το μικρότερο flex ανατίθεται πρώτος σε ΒΑΥΔΜ/ΕΣΤ, ώστε να μην "σπαταλούνται" πολυδύναμοι στρατιώτες σε ειδικές θέσεις.

Ο αλγόριθμος κρατά έναν global `index` που περιστρέφεται (round-robin) μεταξύ ισοβαθμούντων υποψήφιων, αποφεύγοντας να παίρνει πάντα τον πρώτο της λίστας.

## Δύο Λειτουργίες

### Generate — Δημιουργία από μηδέν
```bash
python schedule.py        # ή schedule.exe
```

```
1. read_personnel()     → φόρτωση προσωπικού με όλες τις παραμέτρους
2. read_needs()         → φόρτωση αναγκών ανά ημέρα
3. read_carryover()     → αρχικοποίηση last_service_date από προηγούμενο μήνα
4. clear_schedule()     → καθαρισμός παλιών δεδομένων
5. Για κάθε μέρα:
   └─ fill_service_slots()  → ΜΛΣΝ, ΕΤΑΦ, ΒΑΥΔΜ, ΕΣΤ (κανονικές)
   └─ fill_reserve_slot()   → ΕΠΙΦ_ΜΛΣΝ, ΕΠΙΦ_ΒΑΥΔΜ (εφεδρικές)
6. write_stats_formulas() → τύποι Excel στο Stats sheet
7. validate_schedule()    → έλεγχος παραβάσεων
8. save_snapshot()        → αποθήκευση για μελλοντικό Patch
9. write_carryover()      → αποθήκευση τελευταίων N ημερών
10. backup_excel()        → αντίγραφο ασφαλείας στο backups/
```

### Patch — Επιδιόρθωση
```bash
python schedule.py --patch    # ή schedule.exe --patch
```

Χρησιμοποιείται όταν κάποιος πήρε άδεια απροσδόκητα ή έγινε χειροκίνητη αλλαγή στο Excel.

```
1. load_snapshot_leaves()         → εντοπισμός χειροκίνητα αδειασμένων κελιών
2. load_snapshot_manual_additions() → εντοπισμός χειροκίνητα προστεθέντων
3. read_adeies()                  → φόρτωση αδειών
4. patch_leaves():
   a. καθαρισμός κελιών αδειούχων
   b. pre-compute μηνιαίοι μετρητές από ολόκληρο το schedule
   c. γέμισμα κενών slots με βέλτιστο υποψήφιο
      (με forward-gap check: ελέγχει και μελλοντικές ανατεθειμένες ημέρες)
5. validate_schedule()            → εκ νέου έλεγχος παραβάσεων
6. save_snapshot()                → ενημέρωση snapshot
```

## Validation — Εντοπισμός Παραβάσεων

Η `validate_schedule()` ελέγχει μετά από κάθε εκτέλεση:

- Κενά slots που έπρεπε να είναι γεμάτα (βάσει Needs)
- Διπλή ανάθεση ίδιου στρατιώτη την ίδια μέρα
- Ανενεργός στρατιώτης σε υπηρεσία
- Στρατιώτης σε υπηρεσία που δεν επιτρέπεται (flag = 0)
- Παραβάσεις `posto` κανόνων
- Παραβάσεις `allowed_days`
- `mono_sk` σε καθημερινή
- Υπέρβαση `max_mina`, `max_sk`, `mono_1_ton_mina`, per-service max
- `min_gap` παραβάσεις μεταξύ κανονικών υπηρεσιών
- Gap παραβάσεις μεταξύ κανονικής και εφεδρικής (EPIF_GAP = 2 μέρες)

Αποτελέσματα → sheet **Violations** (κόκκινο highlight). Αν δεν υπάρχουν παραβάσεις → πράσινο "✓ Δεν βρέθηκαν παραβάσεις".

---

## Συνέχεια Μεταξύ Μηνών (CarryOver)

Αποθηκεύει τις τελευταίες `max(min_gap_days) + 1` ημέρες του μήνα στο sheet **CarryOver** (DATE, NAME, TYPE). Το επόμενο Generate τις διαβάζει και αρχικοποιεί τα `last_service_date` / `last_reserve_date`, ώστε να μην δοθεί υπηρεσία σε κάποιον που μόλις υπηρέτησε στο τέλος του προηγούμενου μήνα.
