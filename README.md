# Πρόγραμμα Υπηρεσιών — Military Duty Roster Scheduler

Αυτόματο σύστημα δημιουργίας μηνιαίου προγράμματος υπηρεσιών για στρατιωτική μονάδα. Δέχεται δεδομένα από Excel, εφαρμόζει δεκάδες περιορισμούς δικαιοσύνης και διαθεσιμότητας, και γράφει πίσω το έτοιμο πρόγραμμα στο ίδιο αρχείο.

---

## Χαρακτηριστικά

- **Αυτόματη δημιουργία** μηνιαίου προγράμματος υπηρεσιών (Generate mode)
- **Επιδιόρθωση** υπάρχοντος προγράμματος μετά από αλλαγές/άδειες (Patch mode)
- Υποστήριξη **6 τύπων υπηρεσίας**: ΜΛΣΝ (x4), ΕΤΑΦ (x2), ΕΣΤ (x2), ΒΑΥΔΜ, ΕΠΙΦ-ΜΛΣΝ, ΕΠΙΦ-ΒΑΥΔΜ
- **Αλγόριθμος ισοκατανομής**: αυτόματη ισορροπία φόρτου μεταξύ στρατιωτών
- **Constraint validation**: εντοπισμός παραβάσεων κανόνων με αναφορά στο Excel
- **Αυτόματα backups** πριν από κάθε εκτέλεση
- **Συνέχεια μεταξύ μηνών**: αποθηκεύει ιστορικό (CarryOver) για τον επόμενο μήνα
- Compiled σε standalone **Windows .exe** με PyInstaller

## Παράμετροι Προσωπικού (sheet: Personnel)

| Στήλη | Περιγραφή |
|---|---|
| Όνομα | Επώνυμο και όνομα στρατιώτη |

| max_sk | Μέγιστος αριθμός υπηρεσιών Σαββατοκύριακου/μήνα |
| min_gap | Ελάχιστες μέρες μεταξύ δύο διαδοχικών υπηρεσιών |

## Αλγόριθμος Επιλογής

Για κάθε κενή θέση υπηρεσίας, αξιολογούνται όλοι οι επιλέξιμοι στρατιώτες με βάση:

1. **Αποκλεισμοί** (hard constraints):
   - Είναι σε άδεια την ημέρα αυτή
   - Δεν έχει τις απαιτούμενες ιδιότητες για αυτή την υπηρεσία
   - Έχει κάνει υπηρεσία πιο πρόσφατα από το `min_gap`
   - Έχει ξεπεράσει το `max_monthly` ή `max_sk`
   - Ήδη έχει υπηρεσία ίδιας εβδομάδας (για τακτικούς)

2. **Βαθμολόγηση** (soft constraints — `candidate_priority()`):
   - Λιγότερες συνολικές υπηρεσίες → υψηλότερη προτεραιότητα
   - Περισσότερες μέρες από την τελευταία υπηρεσία → υψηλότερη προτεραιότητα
   - Ισοκατανομή Σαββατοκύριακων

## Τρόπος Εκτέλεσης

### Απαιτήσεις
```bash
pip install openpyxl
```

### Generate — Δημιουργία από μηδέν
```bash
python schedule.py
# ή με το compiled exe:
schedule.exe
# ή με διπλό κλικ στο:
run_scheduler.vbs
```

### Patch — Επιδιόρθωση υπάρχοντος προγράμματος
```bash
python schedule.py --patch
# ή:
schedule.exe --patch
# ή με διπλό κλικ στο:
run_patch.vbs
```

### Μεταγλώττιση σε .exe
```bash
pip install pyinstaller
pyinstaller schedule.spec
```

## Λογική Λειτουργίας

### Generate Mode
```
1. Φόρτωση προσωπικού, αναγκών, ιστορικού προηγούμενου μήνα (CarryOver)
2. Καθαρισμός υπάρχοντος προγράμματος
3. Για κάθε μέρα του μήνα:
   └─ Για κάθε τύπο υπηρεσίας (ΜΛΣΝ, ΕΤΑΦ, ΕΣΤ, ΒΑΥΔΜ, ΕΠΙΦ):
      └─ Βρες τον καλύτερο υποψήφιο → ανάθεση
4. Εγγραφή στατιστικών (τύποι Excel) στο sheet Stats
5. Validation → παραβάσεις στο sheet Violations
6. Αποθήκευση backup + CarryOver για τον επόμενο μήνα
```

### Patch Mode
```
1. Φόρτωση τρέχοντος προγράμματος & αδειών
2. Εντοπισμός κενών θέσεων (μέσω σύγκρισης με Snapshot)
3. Εντοπισμός χειροκίνητων προσθηκών (για προστασία)
4. Για κάθε κενό → εύρεση αντικαταστάτη που τηρεί τους κανόνες
5. Ξανά-εκτέλεση validation
```

## Log Αρχείο

Κάθε εκτέλεση γράφει λεπτομερές log στο `scheduler_log.txt`:
- Timestamp εκτέλεσης
- Αρχείο backup που δημιουργήθηκε
- Άδειες που εντοπίστηκαν
- Αλλαγές που έγιναν (ποιος μπήκε σε ποια υπηρεσία)
- Λόγοι απόρριψης υποψηφίων (για debugging)

## Σημειώσεις

- Το Excel αρχείο πρέπει να είναι **κλειστό** κατά την εκτέλεση του scheduler
- Τα hidden sheets (CarryOver, Snapshot, Exclusions) δημιουργούνται αυτόματα αν δεν υπάρχουν
- Το sheet "Adeies" δημιουργείται αυτόματα αν δεν υπάρχει
- Τα backups αποθηκεύονται στον φάκελο `backups/` με timestamp στο όνομα
